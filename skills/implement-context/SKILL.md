# Implement Context Skill

Implement the context for the current project by setting up and configuring all necessary components and dependencies.

Ask for clarification from stakeholders whenever the context requirements are ambiguous or incomplete.

Document all implementation decisions and configurations clearly and ensure it is accessible to all relevant parties.

Use the `get-context` skill to retrieve and utilize existing context information for the current project.

Only implement changes that have a documented context and have been approved by the relevant stakeholders.
