# Agent Instructions

For every request that changes this repository, use the `workflow` skill (`skills/workflow/SKILL.md`).

Before editing any file outside `context/`, update the relevant specification under `context/` (see `skills/make-change/SKILL.md` and REQ-003). Skip this only for context-neutral changes, and state in the summary that the change was treated as context-neutral and why. Editing skills, `README.md`, or scripts changes harness behavior and is not context-neutral unless it preserves everything the context specifies.
